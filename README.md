# ✨ StyleCraft AI – Online Fabric & Outfit Designer

StyleCraft AI is a fashion design application that helps users explore different clothing styles using the fabric materials they already own.

The application aims to make outfit designing easier by allowing users to upload fabric images, explore outfit models, customize clothing details, and save their preferred designs.

## 🌟 Features

- **Fabric Upload:** Upload and preview fabric images.
- **Outfit Gallery:** Explore different outfit models and styles.
- **Multiple Selections:** Select multiple outfit designs.
- **Design Customization:** Customize neckline, sleeves, dress length, embroidery, and borders.
- **Save Designs:** Save customized design specifications in browser storage.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Harshithareddy3104/StyleCraft-AI.git
```

### 2. Open the project folder

```bash
cd StyleCraft-AI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.
